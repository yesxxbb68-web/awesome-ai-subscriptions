## 怎么读这份对照

- **标价**一律写官方公开的美元价，并注明出处和核验日期。不含税；部分地区结账时会加税，或显示当地货币价。
- **使用额度**多数官方说明是「按用量计，没有固定消息条数」。文中只写官网已经写清的倍数关系（例如 Max 为 Pro 的 5 倍），不猜测每天能发多少条。
- **模型名会改。** OpenAI 帮助中心个别问答仍出现较旧的模型名，功能对照以 [chatgpt.com/pricing](https://chatgpt.com/pricing/) 和帮助中心较新的套餐说明为准；具体能用哪个模型，以账号里的模型选择器为准。
- 本仓库讨论的是 **ChatGPT / Claude / Grok / Gemini 的消费者订阅**，不覆盖各家 API 按量计费（除非官网把「每月 API 额度」写进了订阅权益）。

| Plus | **$20** | 进阶工作和效率 | 需要更强推理、Deep Research、更高额度的 Codex / ChatGPT Work，以及更早用到新功能 | [What is ChatGPT Plus?](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)；$20/月写在该文「Subscription Details」 |
| Pro 100 | **$100** | 研究与编程；三档 Pro 之一 | 用量明显超过 Plus，但不需要 Ultrafast | [About ChatGPT Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers) |
| Pro 200 | **$200** | 比 Pro 100 更多用量 | 高频编程 / 研究，需要更长的 Codex 和 ChatGPT Work 会话 | 同上 |

定价页对 Plus 的功能概括包括：带 GPT-6 的进阶推理、更高的消息和上传额度、更复杂的图像生成、扩展的 Deep Research、更长记忆和上下文、Projects / 定时任务 / GPTs、扩展的 Codex 与 ChatGPT Work，以及新功能的较早体验。Pro 在此基础上提供三档用量、GPT-6 Astra 的 Pro 推理、更长的 Codex / Work 会话、常驻智能体 Dot、更快且额度更高的图像生成等。细节以定价页当时列表为准。

补充（均来自官方帮助中心，核验于 2026-11-15）：

- API 用量 **不包含** 在 Go / Plus 里，单独计费。
- 帮助中心写：Go 与 Free 的日常文本对话都是不限次数，但作图、上传、数据分析等仍有限额，并受防滥用规则约束。
- Pro 的「不限」也受防滥用规则约束。到期后可购买 credits 为部分功能续用，但不能靠改设置绕过限额。
- Ultrafast **只在 Pro 500** 提供。
- 网页订阅可用主流信用卡；通过 iOS / Android 订阅则由 Apple / Google 收银，规则不同。
- **官方礼品卡**目前只在美国出售、只给在美国、以美元计费的 ChatGPT 账号兑换，兑换入口是 [chatgpt.com/redeem](https://chatgpt.com/redeem)。不能用于 App Store / Google Play 里买的订阅。见 [Buying and redeeming OpenAI gift cards](https://help.openai.com/en/articles/20001491-buying-and-redeeming-openai-gift-cards)。

### 地区和支付限制（ChatGPT）

OpenAI 在 [ChatGPT Supported Countries](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries) 列出了目前支持访问的国家和地区。核验当日，这份名单 **不包括中国大陆、香港、澳门**；**台湾在名单中**。官方写明：在未列出的国家或地区访问或提供访问，「可能导致账号被封或暂停」。

[ChatGPT and API services in unsupported countries and territories](https://help.openai.com/en/articles/9131992-chatgpt-and-api-services-in-unsupported-countries-and-territories) 还写了两点：

1. 即使账号是在支持地区注册的，到不支持地区旅行时，也可能无法登录或使用。
2. **使用来自未支持国家的支付方式，会导致无法使用其服务。**

本仓库不提供绕过地区限制的操作说明。是否开通、用什么路径，请先读上述官方条款，再自行判断风险。

## Claude（Anthropic）

官方对照页：[claude.com/pricing](https://claude.com/pricing)

个人档位是 **Free、Pro、Max、Ultra**。价格不含税，官方声明套餐和价格可能调整。

| 套餐 | 官方标价（USD） | 用量关系（官网原文） | 适合谁 | 出处 |
| --- | --- | --- | --- | --- |
| Free | $0 | 每 5 小时和每周都有限量 | 轻度试用、偶尔问答 | [定价页](https://claude.com/pricing) |
| Pro | 月付 **$20**；年付一次性 **$200**（页上写合 **$17**/月） | 比 Free 更多；Pro 的 5 小时额度至少是 Free 的 5 倍 | 日常工作，需要 Claude Code、Projects，以及更多模型 | 同上；[What is the Pro plan?](https://support.claude.com/en/articles/8325606-what-is-the-pro-plan) |
| Max | **$100**/月（仅月付） | 每 5 小时和每周都是 Pro 的 **5 倍** | 全天使用、不想频繁撞限额 | [定价页](https://claude.com/pricing)；[What is the Max plan?](https://support.claude.com/en/articles/11049741-what-is-the-max-plan) |
| Ultra | **$200**/月（仅月付） | 每周是 Pro 的 **10 倍**；通过验证的账号 **没有 5 小时限额** | 超长任务、高频 Claude Code | [定价页](https://claude.com/pricing) |

定价页还写明（核验于 2026-11-15）：

- 网页、桌面、手机和 Claude Code **共用同一份额度**，没有固定消息条数。
- Pro 起包含 Claude Code、任务交接与定时任务、更多模型、Claude in Chrome 和 Microsoft 365 等。
- Max / Ultra 包含优先高峰访问，以及面向 Claude Platform 的每月 API 额度：Max **$100**，Ultra **$200**。
- 顶级模型 Fable：Pro 需用 usage credits；Max / Ultra 可把每周额度的最多一半用在 Fable 上。
- 达到限额后：等重置、升级套餐，或在付费档打开 usage credits，按标准 API 价继续用。

说明：中文社区和部分店铺仍把较高档叫作「Max 5x / Max 20x」。以 2026-11-15 的官网为准，个人付费档名称是 **Pro、Max（5x）、Ultra（$200，每周 10x）**。对照时请看官网当时的名称，不要只看口头习惯。

### 地区政策（Claude）

请以 [Supported Regions Policy](https://www.anthropic.com/legal/supported-regions)（生效日期 **2026-11-12**）为准。政策写明：未列入的国家或地区均不支持，并且限制范围比「人在不支持地区」更宽，还包括：

- 人在不支持地区时使用（包括支持地区公司的员工或访客）；
- 在不支持地区注册或总部设在那里的实体及其人员（即使人在支持地区）；
- 被不支持地区的个人或实体直接或间接控股的实体及其人员。

核验当日，名单 **不包括中国大陆、香港、澳门**；**台湾在名单中**。这份政策比帮助中心较早的「Where can I access Claude?」更新，如两者不一致，以法律页面的生效文本为准。

| --- | --- | --- | --- | --- |
| Free | $0 | $0 | 有限 | 有限的 Chat 和 agent 请求 |
| Plus | **$8**/月 | $80/年 | 基准（1x） | Grok Chat / Voice / Imagine / Build、Grok API、Cursor，以及部分 X 权益。文档写明 **Plus 不含 Grok Bot** |
| Premium | **$30**/月 | $300/年 | **4x** | 发布说明称包含 SuperGrok、Cursor Pro 和 X Premium+ 的权益；含 Grok Bot、更新模型、更快回复等 |

补充（官方原文，核验于 2026-11-15）：

## 怎么选：按使用场景

下面是根据官方定位做的选择建议，不是测评分数。

- **偶尔问问、先试试：** 各家免费档。
- **每天用、但主要是聊天、改写、轻度作图：** 更便宜的入门付费档，例如 ChatGPT Go（美国 $8/月）或 Google AI Plus（$4.99/月）。
- **写代码、做研究、要更强推理和工具：** ChatGPT Plus（$20）或 Claude Pro（$20，可年付 $200）。经常用 Claude Code、Artifacts 做前端或文档的，官方把这类能力放在 Pro 及以上。
- **一天到晚都在用、免费和普通付费档经常撞限额：** Claude Max（Pro 的 5 倍，$100）或 ChatGPT Pro 100 / 200；已经把 Claude 当全天工作台、还要更长会话，再看 Ultra（$200，每周 10x）。ChatGPT 侧需要 Ultrafast 再看 Pro 500。
- **同时要 Grok、Cursor 和 X 权益：** 看 The X Subscription。官方建议轻度 AI 选 Plus，新用户常用 Premium（$30），日常 agent 选 Super，重度用户选 Ultra。
- **已经深度使用 Google 文档、Gmail、云存储：** Google AI Pro / Ultra 的价值不只在聊天，还包含存储和部分 YouTube / Home / Health 捆绑，是否划算取决于你本来就要不要这些服务。

## 从国内开通的常见路径

这里只整理公开、可核对的路径和风险，**不提供规避官方地区或支付限制的操作步骤**。

### 1. 官方订阅（自己付款）

在官网或官方 App 里，用官方支持的支付方式（常见是信用卡，或支持地区的应用商店）给 **本人账号** 开通。这是最直接、也最符合各家条款的方式。前提通常是：账号所在地区被官方支持，并且支付方式也来自支持地区。OpenAI 已写明，使用未支持国家的支付方式会被拒绝服务。

### 2. 官方礼品卡（目前主要是 OpenAI）

OpenAI 有官方 ChatGPT 礼品卡，但帮助中心写得很窄：只在美国购买和兑换，只用于在美国、以美元计费的账号，在网页兑换，不能抵 App Store / Google Play 订阅。把一张美国礼品卡寄到其他国家，并不会让它在当地变得可兑换。核验当日，未见 Anthropic / xAI / Google 有同等范围的「官方 ChatGPT 式礼品卡」说明；请勿把第三方卖的「兑换码」当成官方礼品卡。

### 3. 第三方代充 / 直冲 / 卡密

「代充」或「直冲」一般指：你没有可用的官方支付方式时，由第三方帮你把会员开到 **本人账号** 上；「卡密」则是你拿到兑换码后，在兑换页自己为本人账号兑换。和它们不是一类的是「共享号 / 合租」：那是别人的账号，通常违反官方使用条款，对话也不私密，本仓库 **不推荐**。

选择这类渠道时，建议至少核对这 6 点（整理自 [AI 代充指南](https://www.aizc.club/guide/ai-daichong)）：

1. 会员是否开在本人账号上，能否在官方订阅或账单页看到。
2. 账号要求是否事先写清（已有订阅是否要等到期、商店订阅要不要先取消、试用或异常充值记录、Claude 是否要先完成官方认证等）。
3. 售后规则是否在下单前公开（质保天数、掉订阅如何补或退、哪些情况不保）。
4. 价格是否明显低于官方标价——过低往往来自异常渠道，容易掉订阅或被风控。
5. 是否有订单号和固定客服，出了问题能追溯。
6. 不要为了便宜去用共享号。

## 账号安全提示

- **不要把账号密码交给任何人。** 开在本人账号上的服务，不应索要你的登录密码。
- OpenAI 帮助中心写明：共享账号凭证、转售访问、自动抽取数据都是禁止的，可能被限制使用。见 [About ChatGPT Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers) 中 “Why has my account been restricted?”。
- 不要购买或使用共享号、出租号。对话内容可能被他人看到，账号也可能被改密或封禁。
- 官方礼品卡的 PIN 应视为机密；一旦被兑换，无法退回原卡。不要在公开场合发送完整 PIN。
- 已有 iOS / Google Play 订阅时，先在对应商店取消并等到期，再换其他开通方式，以免重复扣费或开通失败。
- 远低于官方价、承诺「稳过风控」「永不封号」的，需要格外小心。
- OpenAI《使用政策》将于 **2026-11-20** 生效的更新是真的，但官方并未宣布「白名单」，也没有把「对中国统一封号」写成当天新规。真正新写清楚的，主要是给第三方直接开放模型访问的中转 / 网关要先审批。对照说明：[本站核实稿](https://www.aizc.club/blog/openai-nov-20-usage-policies-whitelist-claim)。

## 常见问题

**Q：国内能直接用官方页面订阅吗？**  
A：取决于该产品有没有把你的所在地区列入支持名单，以及你的支付方式是否被接受。就 ChatGPT 和 Claude 而言，核验当日的官方支持名单都不包含中国大陆、香港和澳门。OpenAI 还明确：未支持国家的支付方式会导致无法使用服务。请先读官方地区和支付说明，再决定要不要走其他路径。

**Q：官方礼品卡能不能给国内账号充？**  
A：OpenAI 官方礼品卡目前只服务美国、美元计费的账号，且须在美国兑换。不能把它当成普遍可用的「国内充值方式」。

**Q：ChatGPT 可以年付吗？**  
A：官方帮助中心写明：Go、Plus、Pro 目前都不支持年付，也不能一次预付多个月。Claude Pro 和部分 Team 套餐可以年付；The X Subscription 和部分 Google AI 套餐提供年付选项，以各官网为准。

**Q：Claude 的 Max 20x 还在吗？**  
A：2026-11-15 的 [claude.com/pricing](https://claude.com/pricing) 个人付费档是 Pro、Max（5x，$100）和 Ultra（$200，每周 10x）。若别处仍写「Max 20x」，请对照官网当前名称，不要只看习惯叫法。

**Q：Grok / SuperGrok 现在叫什么？**  
A：新用户面对的是 The X Subscription（Plus / Premium / Super / Ultra）。已有 SuperGrok 的可以保留旧套餐。Premium 被官方描述为包含 SuperGrok 的权益。

**Q：第三方代充是不是官方授权？**  
A：不要把任何第三方默认当成官方授权渠道。xAI 定价页更是明确写了不授权转售。如果选用第三方，请确认会员开在本人账号上，并自己承担官方条款里已经写明的地区、支付和转售风险。
